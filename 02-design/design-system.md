# SECRETS Lounge — дизайн-система

Собрана из двух референсов в `Referens/` (`13.jpg`, `8.jpg`), **перекрашена под реальный интерьер заведения** (раздел «Интерьер» на secretslounge.ru).
Это единая система: одна палитра, одна типографическая шкала, одна сетка, один ритм.

> **Главное правило цвета проекта:** бордового, малинового и сигнального красного в системе нет.
> Единственный акцент — **оранжевый**. Второй цвет — **тёмно-зелёный**. Фон — чёрный и бетонно-серый.

---

## 1. Откуда палитра

Цвета взяты не из референсов, а из самого зала — по фотографиям раздела «Интерьер»:

| Что в зале | Цвет в системе |
|---|---|
| Тёплый вольфрамовый свет, подсветка ниш, неоновая вывеска, гнездо-качели в янтарном свете | `--c-amber`, `--glow-core` |
| Терракотовые кресла, оранжевая обивка | `--c-orange`, `--c-rust` |
| Изумрудно-зелёный бархат диванов, живые растения | `--c-moss`, `--c-moss-deep`, `--c-moss-hi` |
| Серый бетон стен, потолок, чёрные балки | `--c-concrete`, `--c-graphite`, `--c-ink` |
| Граффити-стена, терраццо-столешницы | текстуры, не цвета — работают как фон |

Итог: **тёплый оранжевый свет в холодной серо-чёрной коробке, с зелёными пятнами бархата и листвы.** Сайт должен выглядеть так же.

## 2. Разбор референсов

Из референсов берём **композицию, типографику и приёмы**, но не цвет.

### Референс `13.jpg` — AgentAI (тёмный, свечение)
- Фон почти чёрный; из центра композиции идёт **радиальное свечение**, которое держит весь экран. → у нас это свечение **тёплое, янтарное**, как лампы в зале.
- Главный объект — фотография, залитая светом, с прозрачными краями, вплавленная в фон без рамки.
- Заголовок — крупный тугой гротеск, где **часть слов белая, часть акцентная** прямо внутри одной строки.
- Карточки: тёмное стекло `rgba(255,255,255,.03–.06)`, обводка в 1px по белому с прозрачностью 8%, радиус 16–24px, внутри — крупная цифра + мелкая подпись.
- Микро-лейблы: капсулы (pill) с точкой-маркером, uppercase, мелкий кегль, широкий трекинг.
- Кнопки — pill: одна залитая акцентом, вторая outline.
- Ритм: плотные ряды карточек-статистики чередуются с воздушными зонами текста.

### Референс `8.jpg` — Reload (контраст тёмного и светлого)
- Первый экран — **фото человека в гелевом свете**, растянутое на всю ширину, поверх — крупный uppercase-заголовок в углу. → у нас свет **тёплый оранжевый**, не красный.
- Ниже — **резкий переход в светлую секцию**, где акцент работает уже на светлом фоне. → светлый у нас не белый, а **тёплый песочный** `--c-sand`.
- Заголовки сплошным uppercase, с **градацией цвета внутри абзаца**: часть строк акцентная, часть приглушённая. Текст сам становится графикой.
- В строку заголовка врезаны **цветные «пилюли»-блобы** вместо слов.
- Акцентный глиф — **звёздочка/астериск**, маркер секции.
- Карточки проектов — наезжающая колода со скруглением 20px, у активной — тень и подъём.
- Кнопки — outline-pill со стрелкой ↗.
- Обрамление страницы: контент лежит в «окне» со скруглёнными углами.

### Что берём в проект

| Приём | Откуда | Как применяем в Secrets |
|---|---|---|
| Тёплое свечение как основной свет | 13 | янтарное зарево за героем, за формой брони, за неоновой вывеской |
| Двухцветный заголовок (белый + оранжевый внутри строки) | 13 | главный приём типографики на всех экранах |
| Тёмное стекло + 1px обводка | 13 | карточки акций, статистики, контактов |
| Резкий переход тёмное → светлое | 8 | одна песочная секция (Меню) как «выдох» в середине страницы |
| Uppercase-заголовки с градацией цвета по строкам | 8 | секционные заголовки |
| Астериск как маркер секции | 8 | нумерация / маркировка блоков |
| Pill-кнопки: filled + outline | оба | CTA «Забронировать» и вторичные действия |
| Наезжающая колода карточек | 8 | акции и галерея интерьера |
| Скруглённое «окно» контента | 8 | обёртка страницы на десктопе |
| Зелёный бархат и листва | интерьер | подложки тегов, панель кальянной карты, карточки коктейлей |
| Бетонная текстура | интерьер | фон секций «Кальян» и «Контакты», еле заметная |

## 3. Палитра

```css
:root {
  /* Фоны */
  --c-void:        #040403;  /* самый глубокий фон, края экрана */
  --c-ink:         #0A0A08;  /* базовый фон страницы */
  --c-ink-2:       #131310;  /* фон приподнятых секций */
  --c-graphite:    #1C1C19;  /* карточки, панели */
  --c-concrete:    #3A3A36;  /* бетон, текстурные плоскости */
  --c-concrete-hi: #55554F;  /* светлый край бетона */

  /* Акцент: оранжевый */
  --c-orange:      #F25A1C;
  --c-orange-hot:  #FF7A2E;
  --c-amber:       #FFB259;
  --c-rust:        #A83A12;

  /* Второй цвет: зелёный */
  --c-moss:        #3A5A3E;
  --c-moss-deep:   #1B2C1F;
  --c-moss-hi:     #6E9A6C;

  /* Светлое */
  --c-sand:        #EFE9DE;
  --c-sand-2:      #DCD4C6;
  --c-white:       #FFFFFF;

  /* Текст */
  --t-primary:     #FFFFFF;
  --t-secondary:   rgba(255,255,255,.62);
  --t-muted:       rgba(255,255,255,.38);
  --t-on-light:    #14140F;
  --t-on-light-2:  rgba(20,20,15,.62);

  /* Поверхности и линии */
  --s-glass:       rgba(255,255,255,.04);
  --s-glass-hi:    rgba(255,255,255,.07);
  --s-stroke:      rgba(255,255,255,.09);
  --s-stroke-hi:   rgba(255,255,255,.18);
  --s-stroke-warm: rgba(242,90,28,.35);
  --s-stroke-moss: rgba(110,154,108,.28);

  /* Тёплый оттенок для точечных эффектов (кнопка на hover) — НЕ фоновое
     свечение, см. §8: --g-hero/--glow-core/--glow-edge удалены 30.09.2026,
     были только его компонентами. */
  --glow-soft:     rgba(255,138,40,.18);
}
```

**Градиенты**

```css
--g-section: linear-gradient(180deg, var(--c-ink) 0%, var(--c-ink-2) 55%, var(--c-ink) 100%);
--g-cta:     linear-gradient(135deg, var(--c-amber) 0%, var(--c-orange) 45%, var(--c-rust) 100%);
--g-card:    linear-gradient(160deg, rgba(255,255,255,.07) 0%, rgba(255,255,255,.02) 100%);
--g-moss:    linear-gradient(160deg, rgba(110,154,108,.14) 0%, rgba(27,44,31,.35) 100%);
```

### Правила цвета

- **Оранжевого на экране — не больше ~12% площади.** Он акцент и источник света, а не фон.
- **Зелёный — второй, не равный.** Он держит поверхности (подложки, теги, панели), но никогда не берёт на себя CTA и не красит заголовки. Соотношение оранжевого к зелёному на экране примерно 3:1.
- Оранжевый и зелёный **не встречаются вплотную** — между ними всегда чёрный или бетонный слой. Прямое касание двух насыщенных даёт «новогодний» эффект.
- Белый текст только на тёмном, `--t-on-light` только на `--c-sand`. Промежуточных сочетаний нет.
- Свечение — всегда за контентом (`z-index` ниже), никогда не поверх текста.
- Чистый `#000` не используем: базовый чёрный — `--c-void`.
- **Запрещены в проекте:** бордовый, малиновый, сигнальный красный (`#E8261C` и соседи), синий, фиолетовый, жёлтый как отдельный акцент (жёлтое — только `--c-amber` в свечении). Состояния форм решаются иконкой и текстом, а не цветом.

## 4. Типографика

### Шрифты

| Роль | Основной | Запасной (бесплатный, есть кириллица) |
|---|---|---|
| Display (H1–H2, цифры) | **TT Firs Neue** / **Druk Cyr** | **Unbounded** (Google Fonts) |
| Text (H3–H6, параграфы, UI) | **Suisse Intl** | **Onest** (Google Fonts) |
| Mono (микро-лейблы, счётчики, таймкоды) | **JetBrains Mono** | JetBrains Mono |

Обязательна полная кириллица во всех начертаниях. Подключать `woff2`, `font-display: swap`, subset `latin, cyrillic`. Вариативные версии — приоритетно.

### Шкала (`clamp()` — адаптив без брейкпоинтов)

```css
--fs-display: clamp(56px, 9.5vw, 168px);   /* первый экран */
--fs-h1:      clamp(44px, 6.4vw, 112px);
--fs-h2:      clamp(34px, 4.4vw, 76px);
--fs-h3:      clamp(26px, 2.6vw, 44px);
--fs-h4:      clamp(20px, 1.6vw, 28px);
--fs-lead:    clamp(18px, 1.35vw, 24px);
--fs-body:    clamp(15px, 1.05vw, 18px);
--fs-small:   14px;
--fs-label:   12px;
```

### Начертания и метрики

| Уровень | Вес | Line-height | Letter-spacing | Case |
|---|---|---|---|---|
| Display | 700–800 | 0.88 | −0.03em | обычный или UPPERCASE |
| H1 | 700 | 0.92 | −0.025em | UPPERCASE |
| H2 | 700 | 0.96 | −0.02em | UPPERCASE |
| H3 | 600 | 1.08 | −0.015em | обычный |
| H4 | 600 | 1.2 | −0.01em | обычный |
| Lead | 400 | 1.45 | −0.005em | обычный |
| Body | 400 | 1.6 | 0 | обычный |
| Label (mono) | 500 | 1.2 | 0.14em | UPPERCASE |

### Правила набора

- Длина строки основного текста — 58–68 знаков, `max-width: 62ch`.
- В крупных заголовках переносы расставляются вручную (`<br>` или `text-wrap: balance`).
- **Двухцветный заголовок** — основной приём: ключевое слово красится в `--c-orange`, остальное белое. Не больше одного акцентного фрагмента на строку. Зелёным заголовки не красим.
- Микро-лейблы: mono + uppercase + трекинг `.14em`, перед ними `✳` цветом `--c-orange`.
- Цифры (акции, цены, статистика) — display-шрифт, tabular-nums, вес 700, размер от `--fs-h2`.
- Кавычки — ёлочки «», тире — длинное с неразрывным пробелом перед ним. Внутри «ёлочек» — „лапки“.
- Никаких italic-serif-заголовков и курсивных «изящных» акцентов — прямой пункт slop-детектора.

## 6. Ритм блоков

Страница строится как чередование плотности, а не как список одинаковых секций.

```
ТЁМНО / полный экран   →  Герой: фото зала (свет — от самого кадра, не синтетика), дым
ТЁМНО / воздух         →  О нас: крупный текст, много пустоты
ТЁМНО / плотно         →  Кальян: ровный фон, карточки вкусов
ПЕСОК / воздух         →  Меню: разрыв ритма, светлый тёплый фон
ТЁМНО / плотно         →  Бар: горизонтальная прокрутка коктейлей, зелёные подложки
ТЁМНО / медиа          →  Интерьер: полноширинная галерея зала
ТЁМНО / плотно         →  Акции: колода карточек
ТЁМНО / фокус          →  Бронь: форма по центру
ТЁМНО / спокойно       →  Контакты + карта + футер
```

Сводный список правок, 30.09.2026: синтетическое «зарево» (radial-gradient
за контентом) убрано на всей странице — см. §8. Тёплый свет теперь только
от самих фотографий интерьера, ничего не подсвечено искусственно.

Правила:
- Две подряд одинаковые по плотности секции — ошибка. Между плотными всегда воздушная.
- Одна светлая секция на всю страницу. Две — потеря эффекта.
- Каждая секция начинается с mono-лейбла и номера (`✳ 03 / КАЛЬЯН`).
- Ни один блок не повторяет композицию соседнего.

### Работа с пространством

- Первый экран занимает `100svh`, контент прижат к низу, верх отдан фотографии.
- Пустота — материал, а не остаток. Между заголовком секции и контентом 48–64px.
- Фотографии обрезаются агрессивно: крупный план, кадр без «воздуха» по краям.
- Текст не центрируется целиком, кроме блока брони. Выключка влево.

## 7. Компоненты

**Кнопка primary** — pill, фон `--g-cta`, текст белый, высота 56px (desktop) / 48px (mobile), паддинг 0 32px. Ховер: подъём на 2px, `--sh-glow`.

**Кнопка secondary** — pill, прозрачный фон, обводка `--s-stroke-hi`, текст белый, стрелка ↗ справа. Ховер: обводка → `--s-stroke-warm`, стрелка сдвигается вправо-вверх на 3px.

**Карточка** — фон `--g-card`, обводка `--s-stroke`, радиус `--r-md`, паддинг 32px (24px mobile). Ховер: фон → `--s-glass-hi`, подъём 4px. **Карточка внутри карточки запрещена.**

**Карточка-«бархат»** (коктейли, кальянная карта) — фон `--g-moss`, обводка `--s-stroke-moss`, в остальном как обычная. Использовать точечно, не более одной группы на секцию.

**Микро-лейбл** — mono 12px uppercase, трекинг `.14em`, `--t-muted`, перед текстом `✳` цветом `--c-orange`.

**Инпут** — высота 56px, фон `--s-glass`, обводка `--s-stroke`, радиус `--r-sm`, лейбл уезжает вверх при фокусе, обводка → `--c-orange`.

**Тег/чип** — pill, высота 32px, фон `--s-glass` (или `--c-moss-deep` для вкусов кальяна), обводка `--s-stroke`, mono 12px uppercase.

**Счётчик секции** — display-шрифт, `--t-muted`, формат `01 — 09`.

## 8. Прямые запреты (slop-контроль)

Ниже — то, что детектор `impeccable` и правила `taste-skill` отмечают как признак шаблонного AI-дизайна. В этом проекте не допускается:

- Бежево-серая «AI-палитра» (`#F5F5F5` + `#333` + один синий акцент).
- Курсивный serif в заголовках как «акцент изящности».
- Карточка внутри карточки.
- Тонкая рамка 1px в паре с широкой мягкой тенью на одном элементе.
- Пульсирующая точка-индикатор.
- Цветная полоса-таб слева у карточки.
- Стопки одинаковых иконок в квадратных плитках.
- Плейсхолдерные CTA: «Узнать больше», «Подробнее», «Начать», «Get started».
- Эмодзи в интерфейсе и в заголовках.
- Равномерная сетка из трёх одинаковых карточек в каждой секции подряд.
- Градиентный текст в заголовках (`background-clip: text`) как основной приём.
- Стоковые фото с белым фоном.
- **Бордовый / красный в любом виде** — отдельный запрет этого проекта.
- **Размытые цветные градиенты-пятна и glow на фоне** — `radial-gradient`,
  `filter: blur()`-блобы, псевдоэлементы-«зарево» за контентом. Было в
  hero, about, прелоадере, мобильной nav-panel, отдельной секции «Кальян» —
  убрано целиком 30.09.2026 по сводной правке. Исключение — затемняющий
  скрим поверх фото для читаемости текста (линейный градиент к сплошному
  тону, не цветное пятно) и точечные интерактивные эффекты, которые не
  часть фона (курсорный блик на 3D-карточках кальяна, `box-shadow` на
  hover кнопки) — они не создают фоновой подсветки секции.
- **Одиночные линии-разделители между секциями без функции.** Граница
  между секциями — это только вертикальный отступ (`--section-y`), не
  `border`. Оставлены только функциональные линии: шкалы, разделители в
  рядах фактов, таблицах и внутри одного компонента (например,
  навигация/легал в подвале).

## 9. Доступность

- Контраст основного текста на тёмном ≥ 7:1, вторичного ≥ 4.5:1. `--c-orange` на `--c-ink` даёт ~6.4:1 — годится для UI и крупного текста; для мелкого основного текста использовать белый.
- `--c-moss-hi` на тёмном — только для декора и крупных элементов, не для набора.
- Фокус виден всегда: `outline: 2px solid var(--c-orange-hot); outline-offset: 3px`.
- Вся анимация выключается по `prefers-reduced-motion: reduce` — без исключений.
- Смысл никогда не передаётся одним цветом.
- Минимальная тач-зона 44×44px.
- Тёмная тема — единственная и основная. Песочная секция — часть композиции, а не отдельный режим.
