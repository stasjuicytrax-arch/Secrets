# Техническое задание: сайт SECRETS Lounge

Заказчик: Secrets Lounge Bar, Санкт-Петербург, ул. Полтавская, 7
Проект: полная переработка сайта secretslounge.ru (сейчас — Tilda)
Дата: 29.09.2026

**Формат:** одностраничный сайт (long-read) + отдельная страница меню.
**Цель:** заменить шаблонный Tilda-сайт на авторский, насыщенный анимацией, с сильным визуальным характером — чтобы сайт выглядел так же, как выглядит само место.
**Ключевая метрика:** заявка на бронь стола.

> **Цвет.** Акцент проекта — оранжевый, второй цвет — тёмно-зелёный, фон — чёрный и бетонно-серый. Палитра взята из реального интерьера зала. Бордовый, малиновый и сигнальный красный в проекте запрещены. Подробно — `02-design/design-system.md`, §3.

Хуки включить, чтобы **slop-детектор (61 антипаттерн)** срабатывал автоматически перед коммитом. Список запретов продублирован в `02-design/design-system.md`, §7 — он обязателен к соблюдению.

### `taste-skill` — https://www.tasteskill.dev
Установка: `npx skills add Leonxlnx/taste-skill`

Порядок работы по скиллу:
1. **Brief inference** перед генерацией — индустрия (ночной лаунж/HoReCa), аудитория (25–40, СПб, вечер-ночь), настроение (тёмное, дымное, красный свет), семейство лейаутов (editorial long-read с полноширинными медиа).
2. **Audit-first** — это редизайн, а не новый сайт: сначала аудит старой страницы, потом генерация.
3. **Pre-flight validation** перед выдачей каждого блока.
4. Dual-mode из скилла **не применяем**: сайт только тёмный, песочная секция — часть композиции. Это сознательное отклонение, зафиксировать в `DESIGN.md`.

> Если рекомендации скиллов противоречат дизайн-системе проекта — приоритет у дизайн-системы, расхождение фиксируется комментарием в коде.

Последовательность блоков сохраняет логику старого сайта. Изменения относительно старого: добавлены прелоадер и лояльность как полноценный блок, «Интерьер» перенесён из хвоста на позицию перед «Акциями» — чтобы эмоциональный блок шёл до конверсионного.

### Меню (`/menu`)

Отдельная страница. Категории слева (sticky), позиции справа, фильтр по категориям, ленивые фото. Пока клиент не отдал меню в виде данных — временно оставить PDF-вьюер, но разметку сразу закладывать под позиции.

## 3. Первый экран

```
✳ SECRETS LOUNGE · САНКТ-ПЕТЕРБУРГ

ТВОЙ СЕКРЕТНЫЙ ЛАУНЖ
В СЕРДЦЕ СЕВЕРНОЙ СТОЛИЦЫ
      └── «СЕКРЕТНЫЙ» — оранжевым

Полтавская, 7 · до 06:00 по пятницам и субботам

[ ЗАБРОНИРОВАТЬ СТОЛ ]   [ Смотреть меню ↗ ]
```

- Высота `100svh`, контент прижат к низу.
- Фон: фото зала/дыма в тёплом вольфрамовом свете, поверх — радиальное янтарное свечение `--g-hero`, сверху — плёнка зерна.
- Свечение медленно дышит (8s) и смещается за курсором с задержкой.
- Заголовок выезжает построчно через SplitText, маска снизу, стагер 0.08s.
- Скролл-индикатор внизу, исчезает после первого скролла.

## 4. Анимация

Сайт должен ощущаться живым, но не мешать чтению. Правило: **анимация объясняет структуру, а не развлекает**.

### Глобально
- Lenis: `duration 1.1`, `easing expoOut`, инерция отключена на тач-устройствах.
- Кастомный курсор: точка + кольцо, кольцо увеличивается над интерактивным, над медиа превращается в подпись («смотреть», «перетащить»).
- Шумовое зерно — фиксированный overlay, `opacity .05`, `mix-blend-mode: overlay`.
- Header сжимается в pill на скролле вниз, разворачивается при скролле вверх.
- Прогресс чтения — тонкая оранжевая линия сверху.

### Появление элементов
- Заголовки — SplitText по строкам, маска снизу, стагер 0.06–0.1s.
- Параграфы — fade + подъём 24px.
- Карточки — стагер 0.08s, подъём 40px, лёгкий scale 0.96→1.
- Изображения — раскрытие маской (clip-path) снизу вверх, 0.9s, `--e-out`; внутри картинка едет от scale 1.12 к 1.
- Всё стартует при 80% вьюпорта, `once: true`.

### Скролл-сцены
| Блок | Эффект |
|---|---|
| Герой | заголовок уезжает вверх со скоростью 0.4, фото — 0.7 (паралакс) |
| О нас | цифры-факты отсчитываются от 0 при входе в кадр |
| Меню (светлая) | фон перекрашивается из `--c-ink` в `--c-bone` по мере входа секции |
| Бар | pinned-секция: вертикальный скролл прокручивает карточки коктейлей горизонтально |
| Кальян | сетка вкусов собирается из разлёта, бетонный фон проявляется |
| Интерьер | фото разной скорости паралакса, при наведении — увеличение и подсветка |
| Акции | карточки-колода разъезжаются веером при входе |
| Бронь | свечение вокруг формы усиливается при фокусе в поле |

### Микровзаимодействия
- Магнитные кнопки (притяжение к курсору в радиусе 80px, макс. смещение 12px).
- Стрелка в secondary-кнопке уезжает ↗ и возвращается.
- Ссылки — подчёркивание раскрывается слева направо.
- Инпуты — лейбл уезжает вверх, обводка перекрашивается в оранжевый, за полем зажигается мягкое свечение.
- Бегущая строка между секциями: `SECRETS · LOUNGE · BAR · ПОЛТАВСКАЯ 7 ·` — со скоростью, зависящей от направления скролла.

### Ограничения
- Все ScrollTrigger уничтожаются при смене страницы.
- `will-change` ставится точечно и снимается после анимации.
- `prefers-reduced-motion: reduce` — весь GSAP отключается, Lenis не инициализируется, элементы показываются сразу.
- Анимации не блокируют интерактив: кнопка кликабельна до окончания появления.

## 5. Форма бронирования

Поля (старый сайт их скрывает — состав согласовать с клиентом):

| Поле | Тип | Обязательно |
|---|---|---|
| Имя | text | да |
| Телефон | tel, маска `+7 (___) ___-__-__` | да |
| Дата | date, от сегодня | да |
| Время | select с шагом 30 мин, в пределах режима работы | да |
| Количество гостей | stepper 1–12, «больше 12» → подсказка позвонить | да |
| Комментарий | textarea | нет |
| Согласие на обработку ПД | checkbox со ссылкой на политику | да |

- Валидация на blur, не на каждый ввод.
- Ошибка — текст + иконка, не только цвет.
- Отправка: Telegram Bot API в чат администраторов, дубль на `tsinist@bk.ru`.
- Защита: honeypot + rate-limit по IP. Без капчи.
- Успех — экран с подтверждением и напоминанием, что администратор перезвонит.
- Цель в Метрике на успешную отправку.

## 6. Контент

Весь текст, контакты, акции, режим работы — в `01-content/site-content.md`, ссылки и медиа — в `01-content/links-and-media.md`. Тексты переносятся дословно, кроме:

- опечатки «качествава» → «качества»;
- двух разных написаний расписания → привести к одному;
- плейсхолдерных кнопок («посмотреть меню») → осмысленные CTA.

### Фото
Все фотографии обработаны в едином тёплом свете зала — янтарные лампы, оранжевые кресла, зелёный бархат, серый бетон (см. дизайн-систему, §1, §3). Стоковые фото с белым фоном не использовать. Формат — AVIF + WebP fallback, `<picture>`, ленивая загрузка ниже первого экрана, у первого экрана — `fetchpriority="high"`.

## 7. Технические требования

### Производительность
| Метрика | Цель |
|---|---|
| LCP | < 2.0s (4G) |
| CLS | < 0.05 |
| INP | < 200ms |
| Lighthouse Performance (mobile) | ≥ 85 |
| Вес первого экрана | < 900 KB |
| JS bundle (gzip) | < 180 KB |

GSAP и OGL грузятся отложенно, после первой отрисовки. Шрифты — preload только для двух начертаний первого экрана.

### Адаптив
Брейкпоинты: 1600 / 1280 / 1024 / 768 / 480. Проверка на iPhone SE (375px) и на 2560px. Тач-версия — без кастомного курсора и без магнитных кнопок, pinned-секции заменяются вертикальным листанием.

### Браузеры
Chrome/Edge/Safari/Firefox — две последние версии. Safari iOS 16+. `100svh` вместо `100vh`.

### SEO
- Title: `Secrets Lounge — лаунж-бар на Полтавской, 7 · Санкт-Петербург`
- Description: бар, кальян, японская кухня, бронирование стола, до 06:00 в пт-сб.
- Schema.org: `BarOrClub` + `Restaurant` — адрес, телефон, `openingHoursSpecification`, `menu`, `geo`.
- OG-изображение 1200×630 с фото зала.
- `sitemap.xml`, `robots.txt`, канонические ссылки.
- Редиректы со старых Tilda-анкоров (`#rec980639266` и т.д.) на новые.

### Юридическое
- Знак **18+** в футере.
- Предупреждение о вреде курения и алкоголя в футере.
- Политика конфиденциальности и согласие на обработку ПД (152-ФЗ) — отдельная страница, ссылка в форме и футере.
- Cookie-баннер с раздельным согласием: технические / аналитические / рекламные.

## 10. Открытые вопросы к клиенту

1. Состав полей формы брони — подтвердить предложенный.
2. Меню: нужны данные (позиции, состав, цены) или оставляем PDF?
3. Куда слать заявки: Telegram-чат (нужен chat_id) или почта?
4. Исходники фото и лого в векторе.
5. Реквизиты юрлица и текст политики конфиденциальности.
6. Единый вариант расписания.
7. Нужен ли английский язык.
8. Онлайн-оплата депозита за бронь — в этой версии или потом.
