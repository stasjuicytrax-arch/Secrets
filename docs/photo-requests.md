# Список фото на запрос заказчику

Секция «Бар» (`index.html`, `src/data/cocktails.ts`): у девяти карточек
коктейлей нет реального фото напитка. Каждая карточка временно показывает
один и тот же нейтральный кадр бокала — `public/img/bar/cocktails/_placeholder.webp`
(кроп кадра «Бар Secrets», 4:3) — вместо конкретного напитка. Рисовать или
генерировать коктейли не стали: это не настоящие напитки, а заказчик увидит
и спросит.

Каждая такая карточка помечена в `index.html` комментарием
`<!-- TODO: replace with client photo (Название) -->`.

## Формат подмены

Компонент — обычный `<img src="/img/bar/cocktails/<slug>.webp" onerror="...">`:
если файл с именем напитка есть — показывается он, если нет — `onerror`
подставляет `_placeholder.webp`. Чтобы заменить фото одного коктейля,
достаточно положить файл с тем же именем (и `.avif` рядом) — код трогать
не нужно.

тёмно-зелёный, бетон/чёрный; бордовый и малиновый исключены). Нужен и
`.avif` рядом с каждым `.webp` (та же ширина 420px, см. `scripts/build-images.mjs`).

## Уже есть, менять не нужно

Один реальный кадр коктейля на сайте — карточка «Бар Secrets» (шейкер льёт
коктейль в дымящийся бокал). Честный кадр: ничего конкретного не утверждает
сверх того, что на нём видно.
